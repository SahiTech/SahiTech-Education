# MDI Requirements — Supplemental Overview

**Status:** Consolidated high-level requirements. Numbered product specifications are authoritative.

MDI is a Bangladesh-first, international-ready madrasa operating platform direction. It aims to support institutional governance, Qawmi and Alia academic contexts, student lifecycle, attendance, examination, finance, hostel operations and public institutional information.

## Core requirements
- Tenant-scoped access with database-enforced isolation.
- Separate Global Platform Owner and institutional authorization.
- Configurable Qawmi and Alia academic models.
- Trilingual Bangla, English and Arabic UX, including Arabic RTL.
- Safe student/guardian data handling and verifiable academic records.
- Auditable, transactional financial workflows.
- Secure integrations with provider-side idempotency and error handling.

Features listed here are requirements, not proof of current implementation or production availability. Consult [Implementation Status](../IMPLEMENTATION_STATUS.md) and [Documentation Sync Policy](DOCUMENTATION_SYNC_POLICY.md) before describing a feature as live.
